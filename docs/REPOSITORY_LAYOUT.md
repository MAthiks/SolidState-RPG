# Repository layout

- `engine/` — Solid State engine artifacts and source material.
- `rules/coc7/` — project-owned CoC7 Rules Core artifacts. Do not commit commercial rulebooks unless redistribution is authorized.
- `scenarios/` — scenario integration manifests/adapters; keep proprietary source PDFs out unless redistribution is authorized.
- `manifest/` — machine-readable checkpoint manifests and hashes.
- `docs/` — architecture, anti-rollback policy, procedures.
- `tests/` — regression and certification tests.

Placeholder `.gitkeep` files preserve the initial directory structure until verified payloads are imported.
